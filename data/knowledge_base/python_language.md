# The Python Programming Language

Python was created by Guido van Rossum and first released in 1991. The name comes from the British comedy group Monty Python's Flying Circus, not from the snake.

## Design and features
Python is a high-level, dynamically typed, garbage-collected language. Its reference implementation, CPython, manages memory with reference counting supplemented by a cyclic garbage collector. Blocks of code are defined by indentation rather than braces. The community style guide is PEP 8, and the guiding principles are summarised in PEP 20, "The Zen of Python".

## Versions
Python 3.0 was released in December 2008 and was intentionally not backwards compatible with Python 2. Python 2 reached end of life on 1 January 2020 and no longer receives security fixes. Python 3.13 (October 2024) added an experimental free-threaded build that can run without the Global Interpreter Lock (PEP 703) and an experimental just-in-time compiler (PEP 744).

## Ecosystem
The package installer is pip, and packages are published on the Python Package Index (PyPI). Python is widely used for web development, data science, automation and machine learning. In CPython the Global Interpreter Lock (GIL) allows only one thread to execute Python bytecode at a time, which limits CPU-bound multithreading.
