    Pick a sample or paste a question and an answer, then choose Run arbitration. Each critic checks something different:

    Accuracy
    Is each claim actually true?
    Grounding
    Do the retrieved documents back each claim?
    Consistency
    Does the answer contradict itself or fresh samples of the same question?
    Completeness
    Does it cover everything the question asks for?
